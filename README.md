## Using these notebooks

- Each link opens a read-only copy. Choose **File → Save a copy in Drive** before you start; your copy is private to you.
- Run a cell with **Shift + Enter**. If Colab warns that the notebook wasn't authored by Google, choose **Run anyway**.
- The notebooks load their data from this repository automatically. If loading fails more than once, download the CSV
  files from [data/session1](data/session1) and drag them into Colab's Files panel (the folder icon on the left); the
  notebooks use your uploaded copy automatically.

## About the data

Every dataset here is synthetic. Kestrel Valley Health, its clinics, and the Home BP Coaching Trial are fictional, and no
record describes a real person. Please don't add real patient data to these notebooks.
